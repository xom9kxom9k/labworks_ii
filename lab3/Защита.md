# Пояснения к лабораторной № 3

**Что решает модель?** По уже прочитанному тексту оценивает вероятности
следующего символа. Повторяя этот шаг, получает продолжение.

**Почему GRU?** Она хранит скрытое состояние и учитывает порядок символов.
Ворота обновления и сброса регулируют сохранение прошлой информации.
Это компактная рекуррентная сеть, которую можно обучить на CPU.

**Что делает Embedding?** Превращает целочисленный индекс символа
в обучаемый вектор из 64 чисел. GRU преобразует его в состояние из 256 чисел.
Linear выдаёт 65 логитов. Softmax применяется при генерации;
CrossEntropyLoss при обучении принимает непосредственно логиты.

**Откуда берутся правильные ответы?** Из того же текста. Для входа
`ROMEO` целевой фрагмент содержит следующие символы `OMEO:`.
Таким образом, специальная ручная разметка не нужна.

**Как устроено разбиение?** Первые 80% текста идут на обучение,
следующие 10% на валидацию, последние 10% на тест. Сначала разделяется
текст, затем создаются окна. Перемешиваются только обучающие окна.
Это исключает пересечение соседних окон между разными частями,
но не исключает естественных повторов фраз внутри самого корпуса.

**Как выбираются веса?** После каждой эпохи оцениваются потери на
валидации. Сохраняется модель с минимальными потерями; тест
не используется для выбора эпохи.

**Зачем clipping?** Ограничивает общую норму градиента значением 1,0,
чтобы уменьшить риск слишком больших обновлений весов.

**Что такое perplexity?** Экспонента средней cross entropy.
Меньшее значение означает более уверенное предсказание реальных символов.
Посимвольную perplexity нельзя напрямую сравнивать с метрикой
модели на словах или другом словаре. Она не измеряет смысловую связность.

**Что такое температура?** Логиты делятся на положительное число T.
При T < 1 распределение становится острее, текст обычно более повторный;
при T > 1 чаще выбираются редкие символы и возрастает риск ошибок.
В samples.json сохранены три варианта с одинаковыми затравкой и seed.

**Почему передаётся hidden при генерации?** Чтобы учитывать ранее
сгенерированные символы. Затравка обрабатывается один раз целиком,
затем на вход подаётся только очередной выбранный символ.

**Какие ограничения?** Один seed и небольшой бюджет обучения,
контекст обучения 100 символов, один английский корпус. Возможны
несуществующие слова, повторы и бессмысленные предложения.
Готовая большая языковая модель не использовалась.
