# Лабораторная работа № 3 — Генерация текста

Задание: разработать модель генерации текста по выбранному датасету.
Использованы PyTorch, посимвольная GRU и открытый корпус Tiny Shakespeare.
Текст на английском языке; пояснения и отчёт на русском.

## Запуск в Windows

Нужен 64-разрядный Python 3.13. Откройте терминал в папке `lab3`:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py --evaluate
```

Готовые веса и корпус включены. Интернет нужен только для установки зависимостей.
Генерация с другой затравкой и температурой:

```bat
.venv\Scripts\python main.py --evaluate --prompt "JULIET:" --temperature 0.8 --length 800
```

Модель обучена на английском тексте, русские символы не входят в словарь.
`--evaluate` повторно оценивает готовые веса и обновляет примеры и график.
Для нового обучения: `python main.py`. По умолчанию 10 эпох, результаты
перезаписываются. Для пробы используйте отдельный каталог:

```bat
.venv\Scripts\python main.py --epochs 1 --output trial
.venv\Scripts\python -m unittest -v test_main.py
```

В macOS/Linux используйте `.venv/bin/python`. В рабочем окружении автора
проверено через `../lab1/.venv/bin/python`.
При удалении корпуса: `python prepare_data.py`. Загрузчик проверяет SHA-256.

## Устройство программы

`main.py` читает `data/input.txt` с диска в UTF-8. Последовательные части
корпуса составляют 80% для обучения, 10% для валидации и 10% для теста.
Словарь строится только по обучающей части. Окна по 100 символов не
пересекаются внутри входной последовательности; целевой текст сдвинут
на один символ. Границы частей окна не пересекают. Неполный остаток
каждой части отбрасывается. Скрытое состояние на каждом обучающем окне
обнуляется; контекст обучения ограничен 100 символами.

Embedding(65, 64) → GRU(64, 256) → Linear(256, 65).
Модель предсказывает следующий символ. При генерации скрытое состояние
передаётся между шагами, а следующий символ случайно выбирается из
softmax(logits / temperature). Это авторегрессионная генерация.

Параметры: Adam 0,002; batch size 64; clipping нормы градиента 1,0;
seed 42; CPU, 4 потока. Лучшие веса выбираются по минимальной
валидационной cross entropy. Тест оценивается после этого.
Perplexity = exp(средняя cross entropy); метрика посимвольная.

## Файлы

- `data/input.txt` — исходный корпус, 1 115 394 символа.
- `main.py`, `prepare_data.py`, `test_main.py` — программа, загрузчик, тесты.
- `results/model.pt` — лучшие веса, словарь и контрольная сумма корпуса.
- `results/history.json`, `metrics.json` — история и фактические метрики.
- `results/generated.txt`, `samples.json` — генерация, в том числе при температурах 0,5; 0,8; 1,1.
- `results/learning_curves.png` — кривые обучения.
- `training.log`, `evaluation.log`, `verification.txt` — журналы проверок.
- `Отчет.md`, `Защита.md` — отчёт и пояснения.
