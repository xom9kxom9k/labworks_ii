# Лабораторная работа № 2. Аугментация изображений

Дисциплина: «Системы искусственного интеллекта», 7 семестр.

[Отчёт в формате Word](../reports/Отчёт_ЛР2_СИИ.docx).

Продолжение первой работы: классификация Fashion-MNIST на PyTorch.
Сравниваются две одинаковые CNN: без аугментации и с ней.
Каждая обучается с нуля 16 эпох. У модели с аугментацией первые 8 эпох
проходят на исходных изображениях, следующие 8 с преобразованиями.
Архитектура, начальные веса, разбиение,
порядок обучающих объектов, оптимизатор и число эпох одинаковы.
Аугментация и Dropout используют общий генератор случайных чисел,
поэтому последовательности масок Dropout в двух экспериментах различаются.

Преобразования обучающих изображений:

- горизонтальное отражение с вероятностью 0,5;
- с вероятностью 0,25 применяется аффинное преобразование: поворот
  от −5° до +5°, сдвиг по каждой оси до 3,5% размера изображения,
  масштаб от 0,98 до 1,02.

На этапе аугментации преобразования генерируются заново при каждом обращении к изображению.
Размер остаётся 28×28, метка класса сохраняется. Валидационная и тестовая
выборки не преобразуются. Вертикальное отражение не используется, поскольку
перевёрнутая одежда не соответствует обычным изображениям Fashion-MNIST.

## Запуск в Windows

Рекомендуется 64-разрядный Python 3.13. Откройте терминал в папке `lab2`:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py --evaluate
```

Эта команда проверяет обе готовые модели на локальных данных, пересоздаёт
метрики и графики. Интернет после установки зависимостей не нужен.

Повторное обучение обеих моделей с нуля с перезаписью результатов:

```bat
.venv\Scripts\python main.py
```

Короткая проба: `python main.py --epochs 1`. Она перезапишет готовые веса
и результаты; перед пробой сохраните их копию. Для повторения полного
эксперимента используйте стандартные 16 эпох.

Тесты:

```bat
.venv\Scripts\python -m unittest -v test_main.py
```

Если данные удалены: `python prepare_data.py`. Загрузчик проверяет MD5.
В macOS/Linux вместо `.venv\Scripts\python` используйте `.venv/bin/python`.
Если среда первой работы уже создана, можно использовать
`../lab1/.venv/bin/python main.py`.

## Файлы и результаты

| Путь | Содержимое |
| --- | --- |
| `main.py` | CNN, аугментация, обучение, оценка и графики |
| `test_main.py` | Три автоматические проверки |
| `prepare_data.py` | Загрузка датасета на диск |
| `data/FashionMNIST/raw/` | Локальный датасет |
| `results/baseline/` | Веса, история, метрики и изображения без аугментации |
| `results/augmented/` | Те же результаты с аугментацией |
| `results/augmentation.png` | Оригиналы и случайные преобразования |
| `results/comparison.png` | Сравнение кривых валидации |
| `results/comparison.json` | Метрики и изменение точности в процентных пунктах |
| `Отчет.md` | Ход работы и фактические результаты |
| `Защита.md` | Объяснение решения и ответы на вопросы |
| `training.log` | Вывод выполненного обучения |
| `experiments/strong/` | Результаты предварительной проверки более сильной аугментации |
| `experiments/mild/` | Мягкая аугментация с первой эпохи, предварительная проверка |

В каждом каталоге эксперимента: `model.pt`, `history.json`, `metrics.json`,
`learning_curves.png`, `predictions.png`, `errors.png`, `confusion_matrix.png`.
Модель выбирается по минимальным потерям на валидации; тест не участвует
в выборе эпохи. Seed: 42. CPU: четыре потока, batch size: 128, Adam: 0,001.
Между платформами и версиями библиотек возможны отличия результатов.
Предварительная сильная аугментация ухудшила валидационные метрики;
мягкая с первой эпохи тоже уступила baseline по валидации.
В окончательной программе используется обучение сначала без преобразований,
затем с мягкой аугментацией. При другом числе эпох этап без преобразований
занимает `epochs // 2` эпох; при одной эпохе аугментация включена сразу.
