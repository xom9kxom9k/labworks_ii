# Лабораторная работа № 4. Сегментация изображений

Небольшая U-Net на PyTorch выделяет пешеходов на изображениях Penn-Fudan.
Задача бинарной семантической сегментации: каждый пиксель относится к человеку
или фону. Маски отдельных людей объединяются, экземпляры не разделяются.
Модель обучается с нуля, готовые предобученные веса не используются.

## Запуск в Windows

Нужен 64-разрядный Python 3.13. В терминале в папке `lab4`:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python prepare_data.py
.venv\Scripts\python main.py --evaluate
.venv\Scripts\python -m unittest -v test_main.py
```

Готовая модель включена в репозиторий. Перед первым запуском скачайте
датасет с сайта авторов командой `python prepare_data.py`. После загрузки
данных и установки зависимостей интернет не требуется. `--evaluate` повторно загружает веса и обновляет
тестовые метрики, графики и примеры. Обучение заново: `python main.py`.
По умолчанию выполняется 30 эпох с перезаписью каталога `results`.
Для пробы, сохраняющей готовые результаты:

```bat
.venv\Scripts\python main.py --epochs 1 --output trial
```

В macOS/Linux используйте `.venv/bin/python`. В рабочем окружении автора
проверено через `../lab1/.venv/bin/python`.
При первом запуске или удалении датасета выполните `python prepare_data.py`: загрузчик скачивает
архив с сайта авторов, проверяет SHA-256 и распаковывает изображения и маски.

## Данные и модель

В Penn-Fudan 170 фотографий с 345 размеченными пешеходами.
Загрузка с диска: `data/PennFudanPed/PNGImages` и `PedMasks`.
Значение 0 в маске означает фон, значения больше 0 объединяются в человека.
RGB-изображения уменьшаются до 128×128 (bilinear), маски до того же размера
(nearest, без промежуточных значений классов). Пиксели RGB делятся на 255.
Изменение размера не сохраняет пропорции; метрики считаются на сетке 128×128.

Разбиение по изображениям с seed 42: 120 обучающих, 25 валидационных,
25 тестовых. Списки файлов сохранены в `results/split.json`.
При обучении с вероятностью 0,5 изображение и маска одновременно отражаются
по горизонтали; валидация и тест остаются без аугментации.
В датасете есть похожие уличные сцены. Разбиение по независимым сценам
не выполнялось, поэтому результат не доказывает перенос на новые условия.

U-Net имеет два уровня понижения разрешения: свёрточные блоки 3→16→32→64,
затем транспонированные свёртки 64→32→16 и объединение с признаками
кодировщика. В каждом блоке две свёртки 3×3 с ReLU. Последняя свёртка 1×1
даёт один логит для каждого пикселя. Sigmoid переводит его в вероятность;
порог для маски 0,5, установлен заранее и на тесте не подбирается.

Обучение: Adam, lr 0,001; batch size 8; 30 эпох; CPU, 4 потока.
Потери: BCEWithLogits + (1 − soft Dice), с единичным сглаживанием Dice
для каждого изображения. Лучшие веса выбираются по наибольшему
**глобальному IoU человека на валидации**. Тест оценивается после выбора.
Обучающие метрики собираются по ходу эпохи при обновляемых весах.

## Метрики

Для класса человека TP означает верно выделенный пиксель, FP — лишний
пиксель человека, FN — пропущенный, TN — верный фон.

- IoU = TP / (TP + FP + FN).
- Dice = 2TP / (2TP + FP + FN).
- Pixel accuracy = (TP + TN) / число пикселей.

Основные IoU и Dice суммируют TP/FP/FN по всей выборке (micro).
`mean_image_iou` и `mean_image_dice` усредняют отдельные изображения.
Для двух пустых масок IoU и Dice считаются равными 1.
Высокая pixel accuracy сама по себе недостаточна из-за доли фона:
в `metrics.json` также посчитан контроль «всё фон».

## Файлы

- `main.py` — данные, U-Net, обучение, метрики и визуализация.
- `prepare_data.py`, `test_main.py` — загрузчик и четыре теста.
- `results/model.pt` — веса, контрольная сумма данных и разбиение.
- `results/history.json`, `metrics.json`, `per_image.json` — числовые результаты.
- `results/split.json` — точные списки выборок.
- `results/learning_curves.png` — обучение и валидация.
- `results/predictions.png` — первые четыре тестовых изображения.
- `results/errors.png` — четыре наименьших IoU на тесте.
- `training.log`, `evaluation.log`, `verification.txt` — журналы запусков.
- `Отчет.md`, `Защита.md` — фактические результаты и пояснения.

Исходные фотографии и маски Penn-Fudan не публикуются в репозитории.
Загрузчик получает их с сайта авторов; исходный README с условиями
использования сохраняется рядом с данными.
